# Planning

One planner file per person. Each of us tracks our own progress here so the
other two can see where things stand without having to ask.

| File | Person | Layer |
|------|--------|-------|
| [jun.md](jun.md) | Jun | Hardware and traffic generation |
| [aki.md](aki.md) | Aki | Data, ML, anomaly detection, alert logic |
| [toma.md](toma.md) | Toma | Attack simulation and validation |

## How to use these

- **Edit only your own file.** If you need something from someone else, put it
  under your own **Blocked on** section rather than editing their file.
- **Tick a checkbox when a step is actually done**, not when it's started.
- **Add a dated line to your Log** when you finish something or hit a wall.
  Keeps the history readable without needing to dig through commits.
- Keep it short. This is a status board, not a report.

## Where things live

- **This repo** is public — everything committed here is visible to anyone.
  Keep it to work product: code, results, writeups.
- **Internal discussion** (concerns, opinions, where the project should go
  after v1, anything we'd rather not publish) goes in the team Google Doc,
  which is shared privately between the three of us.
